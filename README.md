# freehands
# 🤖 프리핸즈 리더 (Free-hands Reader)

> **"양손이 자유롭지 않은 상황에서 파란 장갑을 낀 손의 위치를 인식하여 폐기물 처리 과정을 돕는 똑똑한 눈"**

실험실, 병원, 연구실 등에서 양손에 오염 물질이나 실험 도구를 들고 있어 쓰레기통을 직접 만지기 어려운 상황을 해결하기 위해 개발된 **스마트 비접촉(Non-touching) 분리수거 시스템**입니다.

---

## 👥 팀원 소개 (Team Members)
* **4조:** 김서영, 임정규, 최현민, 이지민, 조연선

---

## 🔧 시스템 동작 과정 (System Process)

본 시스템은 웹캠(카메라) 기반의 AI 인식 기술과 아두이노 하드웨어 간의 시리얼 통신을 통해 유기물과 폐기물을 자동으로 판별하고 제어합니다.

1. **입력 (Input):** 웹캠이 사용자가 착용한 파란 장갑의 위치를 실시간으로 촬영하고 인식합니다.
2. **판단 (AI Processing):** 학습된 AI 모델이 카메라 화면을 분석하여 손이 **왼쪽 영역**에 있는지, **오른쪽 영역**에 있는지 분류합니다.
3. **전달 (Communication):** AI의 판단 결과를 시리얼 통신을 통해 연결된 아두이노 보드로 실시간 전송합니다.
4. **출력 및 구동 (Output):**
   * 🟢 **손이 왼쪽 영역일 때:** LCD 화면에 `ORGANIC` 문구와 함께 통이 닫히기까지의 남은 시간이 표시되며, 서보 모터가 왼쪽으로 회전하여 유기물 보관함을 개방합니다.
   * 🔴 **손이 오른쪽 영역일 때:** LCD 화면에 `INORGANIC` 문구와 남은 시간이 표시되며, 폐기물 보관함 메커니즘을 구동합니다.
---

## 💡 기대 효과 및 활용 방안 (Effect & Application)
* **위생적인 폐기물 관리:** 손을 전혀 대지 않는 비접촉 방식(Non-touching)으로 병원 및 연구실 내 2차 감염과 오염을 예방합니다.
* **스마트 분리수거 확장:** 서보 모터를 활용한 자동 개폐 기능을 결합하여 일상적인 쓰레기통 보관함 시스템으로 쉽게 확장 적용할 수 있습니다.
* **지속 가능한 성능 향상:** 실험실마다 달라지는 조명이나 장갑 색상에 유연하게 대응할 수 있도록, 실시간 환경 데이터와 사용자 피드백을 축적해 AI 모델을 지속적으로 재학습시키는 현장 최적화 기능을 지원합니다.
